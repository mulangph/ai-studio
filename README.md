# 🎨 AI Creative Studio

Generate stunning AI images from text prompts using open-source Stable Diffusion models with an intuitive Gradio interface.

This project demonstrates how to build a modern generative AI application using Hugging Face Diffusers, and Gradio. It is designed as a portfolio project showcasing practical AI engineering skills including model inference, UI development, and deployment.

---

## ✨ Features

- 🖼️ Text-to-Image generation
- 🎨 Multiple artistic styles
- 📐 Custom image sizes
- 💻 Simple Gradio web interface
- 🔓 Uses open-source models
